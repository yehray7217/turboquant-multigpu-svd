# LoftQ-Inspired Residual Testcase

This testcase prepares a real AI matrix for `randomized_svd_multigpu_v4` by computing a quantization residual:

```text
R = W - Q(W)
```

The target is a dense LLM weight tensor, stored as a raw `float32` row-major matrix for distributed rSVD benchmarking.

## Recommended Tensor

- Model: `mistralai/Mistral-7B-v0.1`
- Tensor: `model.layers.0.mlp.gate_proj.weight`
- Expected shape: about `14336 x 4096`

Debug option:

- Model: `TinyLlama/TinyLlama-1.1B-Chat-v1.0`
- Tensor: `model.layers.0.mlp.gate_proj.weight`
- Expected shape: about `5632 x 2048`

## Preprocessing

Run the script from this directory:

```bash
python3 scripts/prepare_loftq_residual_matrix.py \
    --model-id mistralai/Mistral-7B-v0.1 \
    --tensor-name model.layers.0.mlp.gate_proj.weight \
    --output matrix.f32 \
    --meta meta.json
```

Debug example:

```bash
python3 scripts/prepare_loftq_residual_matrix.py \
    --model-id TinyLlama/TinyLlama-1.1B-Chat-v1.0 \
    --tensor-name model.layers.0.mlp.gate_proj.weight \
    --output matrix_debug.f32 \
    --meta meta_debug.json
```

The default implementation uses documented fallback quantization:

- row-wise symmetric signed 4-bit quantization
- integer range `[-7, 7]`
- `Q(W)` computed by dequantizing the rounded int4 codes

This is a LoftQ-inspired residual benchmark, not a full LoftQ training reproduction.

## Sanity Check

The script prints:

- tensor shape and dtype
- residual mean, std, mean abs, max abs
- `||R||_F / ||W||_F`
- `has NaN` / `has Inf`
- file size check

## Benchmark Commands

The `exp_turboquant/` folder contains:

- `ctrl.slurm` for no compression
- `b8-exp.slurm` for TQ 8-bit
- `b4-exp.slurm` for TQ 4-bit

All runs use `--input-file testcases_real_world/LoftQ/matrix.f32`, `--subspace-iter 1`, and two phases:

- timing with `--no-check-error`
- final-error without `--no-check-error`

## Notes

- `matrix.f32` and `meta.json` are generated by the preprocessing script and are intentionally ignored by git.
- If you switch to another model or tensor, update `--m` and `--n` in the Slurm scripts to match the generated matrix.
- `theoretical` and `err ratio` are `n/a` for this real-world testcase.
