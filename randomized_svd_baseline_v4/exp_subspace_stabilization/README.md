Evaluate whether QR-orthogonalizing the intermediate `Z = A^T Q` improves q=1 and q=2 subspace iteration accuracy on a 32k x 8k polynomial-decay spectrum matrix without TQ or QJL.


## Result 

(Negative)

Z-side QR stabilization increased runtime by ~15.35 ms and worsened final reconstruction error from 43.68% to 45.35%.

q=1 also negative.
