  generated by `docs/notes/code/sv-distribution-image.py`

  (referenced in notes but not generated by this repo)

## Notes

- The `.webp` files are web-format images. They render in most modern browsers
  and GitHub markdown. If viewing offline in a PDF/presentation, export them
  to PNG first.
- No code changes are needed in this directory — it's purely reference material.
